# Risk register

When triggered, always produce:

1. **Context** in 2 sentences: the organisation and its critical assets.
2. **Risk table** with columns: ID | Threat | Vulnerability | Asset | Likelihood (1-5) | Impact (1-5) | Level (L x I) | Treatment (mitigate/transfer/accept/avoid) | Proposed control
3. Sort the table from highest to lowest level.
4. **Top 3 priorities**, each with one actionable recommendation.
5. If key information is missing, list the assumptions at the end.

Language: answer in the user's language.
